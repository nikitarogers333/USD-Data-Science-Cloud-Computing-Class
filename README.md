## Setup

Clone this repository, then follow the nested installation instructions from the project directory:

```bash
git clone https://github.com/nikitarogers333/USD-Data-Science-Cloud-Computing-Class.git
cd USD-Data-Science-Cloud-Computing-Class/REAL-Glass-Project
conda env create -f environment.yml
conda activate pymeria
```

Dataset access and selected sequence downloads are separate steps described in the nested README. Start with a small sample rather than the full dataset. Review the included license before downloading or reusing data.
